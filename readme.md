## PROGRAMMING LANGUAGES | OBJECT-ORIENTED PROGRAMMING | TU-SOFIA

This repository contains materials and resources related to the Object-Oriented Programming course offered at the Technical University of Sofia (TU-Sofia). The course covers fundamental concepts of object-oriented programming, including classes, objects, inheritance, polymorphism, encapsulation, and design patterns.
